# POC-RobotArm Web

Phase 0 web skeleton: Vite + React 18 + TypeScript + Tailwind + react-three-fiber. Future phases add the real UI panels (jog, code preview, vision overlay, planning, I/O monitor).

## Run

Requires Node 20 and pnpm 10.

    pnpm install
    pnpm dev        # http://localhost:5173
    pnpm build
    pnpm typecheck
